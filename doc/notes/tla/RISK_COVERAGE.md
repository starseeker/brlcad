# Historical and prospective risk coverage

This matrix was derived from `libbobol_engineering_lessons.md`, the active-debt
and production-readiness records, implementation comments, regression names,
and retained TLC coverage.  Past failures are seeds, not the boundary of the
audit: the “prospective variants” column names adjacent failures which the
same mechanism can plausibly produce.

Status meanings:

- **checked**: a TLA+ invariant/property and an executable C++ witness exist;
- **formal added**: the control risk is modeled, but the listed refinement
  regression must still be made explicit;
- **implementation audit**: TLA+ states the contract, while code inspection,
  fault injection, sanitizers, or stress must establish the data-plane edge;
- **outside TLA+**: retain executable, graphical, or performance evidence.

## New roadmap obligations

The audit makes these near-term C++ checks explicit:

1. **Completed:** runtime transition export covers every registered controller
   effect boundary, self-reports unmapped writers, and includes the exact
   renderer-preparation remaining rank.
2. **Completed:** deterministic resource denial at retained-scene,
   presentation, hierarchy-record, and final durable-mapping commit boundaries
   preserves the prior publication and notification identity.
3. **Completed:** endpoint loss during an open gesture, active worker
   generation, and claimed capacity frame atomically retires every controller
   and host owner; callback teardown covers external, self, and nested removal.
4. **Completed:** every six-domain evidence-stamp constructor and reducer
   write is compile-constrained; no defaulted companion field can create an
   unrecorded semantic transition.
5. Keep geometry, numeric, image, performance, and concurrency qualification
   as independent gates; they are refinement evidence, not consequences of
   TLC success.
6. **Completed:** fixed-width authentication, ordering, and ownership counters
   in libBObol and the Obol CAD evidence producer share a checked fail-stop
   successor; externally observed Obol sequences survive resource teardown;
   diagnostic counters saturate; the finite exhaustion model and boundary/
   session tests prohibit ABA reuse.
