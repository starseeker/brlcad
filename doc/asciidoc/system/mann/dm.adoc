== NAME
dm - inspect and configure Obol display endpoints

== SYNOPSIS

[source]
----
dm [-h] [-v] {subcommand} [args]
----

[[description]]
== DESCRIPTION

The *dm* command is the GED policy and diagnostics surface for Obol display
endpoints.  It reports endpoint, host, and renderer state and reads or writes
typed endpoint properties.  It does not discover or configure legacy display
manager backends.

Commands target the active GED view unless their *-V* _view_ option selects a
named view.  Unsupported hosts, renderers, properties, and property values
fail explicitly.

[[options]]
== OPTIONS

*-h*, *--help*::
Print top-level or subcommand help.

*-v*, *--verbose*::
Increase top-level command verbosity.

== ENDPOINT SUBCOMMANDS

*bg* [*-V* _view_] [_bottom-color_ [_top-color_]]::
Query or set the endpoint background.  One color selects a solid background;
two colors select a bottom-to-top gradient.

*close* [*-V* _view_]::
Detach the selected view's presentation host while retaining its endpoint and
scene.

*diagnostics* [*-V* _view_]::
Report endpoint identity, host and renderer capabilities, controller status,
and every readable typed property.  When the *diagnostic* renderer is
selected, this command also advances its non-graphical retained-scene report.

*get* [*-V* _view_] [_property_ ...]::
Read one or more typed endpoint properties.  With no property argument, list
all readable properties and their values.

*host* [*-V* _view_]::
Report the selected endpoint's host factory name, or *unbound*.

*list* [*endpoints*|*hosts*|*renderers*]::
List endpoint-backed GED views, registered host factories, or recognized
renderer policies.  The active endpoint is marked with an asterisk.

*open* [*-V* _view_] *--host* _name_ [*--renderer*
*auto*|*hw*|*sw*|*rt*|*none*|*diagnostic*]::
Open a registered host factory for the selected endpoint.  Host replacement
is staged; an unavailable host or incompatible explicit renderer leaves the
request failed rather than silently selecting another renderer.

*renderer* [*-V* _view_]
[*auto*|*hw*|*sw*|*rt*|*none*|*diagnostic*]::
Query or select the renderer policy.  *none* retains the scene without
graphical rendering.  *diagnostic* performs retained traversal and reporting
without posing as a graphical backend.  A factory-bound *auto* policy resolves
deterministically to *hw* when System GL is available and otherwise to *sw*
when pixel presentation is available.  It never selects *rt* implicitly.  The
read-only *endpoint.renderer.resolved* property reports that result.

*set* [*-V* _view_] _property_ [_value_]::
Query or assign one typed endpoint property.  Boolean values accept *true*,
*false*, *on*, *off*, *1*, *0*, or *!* to toggle.  Color values use
_r/g/b_ or _r,g,b_.  Prefer canonical dotted property names shown by
*dm get* or *dm diagnostics*.  Unknown names fail explicitly; legacy backend
option aliases are not accepted.

*status* [*-V* _view_]::
Report the selected view, host, renderer, pixel dimensions, and device pixel
ratio on one line.

== MGED INPUT SUBCOMMANDS

MGED additionally accepts *dm idle*, *dm m*, *dm motion*, *dm am*, *dm adc*,
*dm con*, and *dm size* as application-owned semantic input and view-sizing
commands.  They act on MGED's current endpoint-backed view; they are not
renderer backend operations.  Their forms are:

[source]
----
dm idle
dm m x y
dm motion x y
dm am r|t|s x y
dm adc 1|2|t|d x y
dm con r|t|s x|y|z x y
dm con a x|y|1|2|d x y
dm size [width height]
----

[[examples]]
== EXAMPLES

.Inspect the active endpoint and its supported renderer policies.
[example]
====
mged>**dm status**
mged>**dm get endpoint.renderer.supported**
====

.Select software presentation and enable renderer lighting.
[example]
====
mged>**dm renderer sw**
mged>**dm set renderer.lighting true**
mged>**dm set renderer.headlight.color 1/0.9/0.75**
mged>**dm set renderer.headlight.intensity 0.8**
====

.Inspect another view without changing the active view.
[example]
====
mged>**dm diagnostics -V upper_left**
====

.Select a gradient background.
[example]
====
mged>**dm bg 20/24/32 70/80/100**
====

.Retain the scene and collect a non-graphical diagnostic traversal.
[example]
====
mged>**dm renderer diagnostic**
mged>**dm diagnostics**
====
