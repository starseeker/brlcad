BRL-CAD libbv Refactor Plan
===========================

Last refreshed: 2026-07-07

Purpose
-------

libbv is the clean BRL-CAD view-mechanics library.  It restores the useful
idea behind historical libbv without preserving its old API or the later BSG
scene ownership model.

Active Goals
------------

* Centralize non-scene view math and view state so librt, libged, qtcad, and
  applications do not grow incompatible implementations.
* Keep scene, selection, LoD, command visualization, and display-object
  behavior in Obol/libbrlobol.
* Remove legacy BSG adapters once callers have native libbv and Obol paths.

libbv Owns
----------

* View/camera state.
* model2view, view2model, pmodel2view, pmat, rotation, and center matrices.
* View dimensions, scale, size, perspective, and unit conversion.
* Autoview from explicit bounds.
* Screen/view/model coordinate transforms.
* Generic mouse/current-point state used for view manipulation.
* Generic knob state and knob command interpretation.
* View-set bookkeeping and display-independent dirty/refresh counters.

libbv Does Not Own
------------------

* Obol or Coin scene nodes.
* Database sources, display lists, or drawable geometry.
* Selection, snapping, picking, polygons, feature stores, annotations, or
  command visuals.
* LoD payloads or draw caches.
* Framebuffer protocol handling or display-manager windows.
* TclCAD/qged/MGED application policy.

Current State
-------------

Implemented scaffold:

* `include/bv.h`
* `include/bv/view.h`
* `src/libbv/view.c`
* `src/libbv/tests/view.c`

Native librt view contexts are libbv-backed:

* `src/librt/view_context_native.c`
* `src/librt/view_context_adapters.c`
* `src/librt/view_context_private.h`

Neutral `rt_view_context_create*` paths create native/libbv-backed contexts.
Explicit `_bsg` constructors still exist only for retained fallback tests and
old callers.  Native contexts return empty/no-op results for scene behaviors
unless an Obol/libbrlobol adapter is installed.

Remaining Work
--------------

1. Split neutral RT view wrappers out of `src/librt/view_legacy_bsg.c` into a
   non-legacy source file.
2. Audit GED, qtcad, MGED/TclCAD, and GSH for callers that still create or
   assume retained BSG view contexts.
3. Convert remaining scene/interaction operations exposed through
   `rt_view_context_*` to Obol/libbrlobol APIs or explicit no-op adapter
   behavior.
4. Remove explicit BSG constructors and tests once no production workflow
   needs them.
5. Keep libbv tests focused on pure view mechanics: matrices, autoview,
   transforms, knobs, view-set bookkeeping, and dirty/refresh state.

Verification
------------

* `ninja -C build libbv librt libged libqtcad`
* `ctest --test-dir build -R '^(bv_basic|rt_view_info|ged_test_view_command|ged_test_obol_draw_sync|test_qtcad_obol)' --output-on-failure`
* `git diff --check`
