== NAME
brlman - manual page viewer for BRL-CAD

== SYNOPSIS

[source]
----
brlman [options] [manpage] [section]
brlman -k keyword
brlman -K keyword
----


[[description]]
== DESCRIPTION

*brlman* is a manual page viewer for BRL-CAD programs, libraries, file
formats, and *mged*(1)/GED commands. On Unix-like systems it wraps the system
*man*(1) command, supplying the paths needed to locate BRL-CAD's installed man
pages when input and output are terminals. On systems lacking a *man* command,
*brlman* formats the installed HTML pages for its built-in terminal viewer.
Redirected output is formatted text without terminal controls. When the GUI
is explicitly requested, *brlman* launches a graphical HTML viewer. The
terminal and HTML pages are generated from the same source and contain
identical information. Builds with FLTK enabled use
an FLTK/litehtml viewer with a manual section selector, page-name filter,
in-page search, and Back/Forward navigation. The same viewer is available from
*fltkged*'s Help menu.

The page to display is given by name. An optional one-character _section_ may
be supplied either as a positional argument or via *-S*. If no section is
given, *brlman* searches sections 1, 3, 5, and n in that order and shows the
first match. With no arguments at all, the graphical viewer (where available)
opens to a browsable index.

Search mode lists matching manual pages in ranked order instead of opening a
single page. The *-k* option searches page names, synopsis text, and brief
descriptions. The *-K* option searches the full manual page text. When no
section is selected, all BRL-CAD manual sections are searched.

In the Tcl/Tk graphical viewer, drag to select text, double-click to select
a word, or triple-click to select a paragraph. Right-click the HTML view
for Copy, Select All, and Find. On X11, selected text is also available
for middle-button pasting in other applications; Copy separately updates
the clipboard.

Control-F (Command-F on macOS) opens a find bar for the displayed page.
Matches are highlighted as the query changes. F3 and Shift-F3 move to the
next and previous matches; Return and Shift-Return do the same while the
find entry has focus. Match case enables case-sensitive searching.
Escape closes the find bar and clears its highlights. The sidebar search
continues to search the manual collection.


[[options]]
== OPTIONS

*-h*, *--help*::
  Print a usage summary and exit.

*-g*, *--gui*::
  Force the graphical man page viewer, even where the terminal *man* command
  is available.

*--no-gui*::
  Disable the graphical viewer. Use the system *man* command when available
  on a terminal, otherwise format the installed HTML page.

*--dump*::
  Write formatted text to standard output without paging, styling, or terminal
  controls. This is also the default when input or output is not a terminal.

*--width* _columns_::
  Set a positive text wrapping width and use the built-in HTML formatter.
  The default is the terminal width for interactive viewing, or 80 columns
  for dumped output. Literal examples retain their original line breaks and
  may exceed this width. Tables too wide for columns use individual cells,
  labeled with column headings where possible.

*--pager*::
  Use the built-in HTML terminal viewer even if the system *man* command is
  available. Arrow keys scroll vertically and horizontally; Space and *b*
  page forward and backward; Home/End or *g*/*G* go to the beginning/end;
  */* enters a case-sensitive search; *n* finds the next match; *q* quits.
  The display reflows on terminal resize. Terminals without the required
  interactive capabilities receive plain formatted output.

*-L* _lg_, *--language* _lg_::
  Two-letter language code (e.g. *en*) used when selecting man pages. If not
  given, *brlman* uses the first two characters of the *LANG* environment
  variable, falling back to *en*.

*-S* _#_, *--section* _#_::
  Section to search. Useful when a program and a GED command share a name; the
  default page is the program (section 1), so *-S n* selects the GED command
  page instead. Allowed sections are 1 (programs), 3 (libraries), 5
  (conventions/formats), and n (GED commands).

*-k* _keyword_, *--keyword* _keyword_::
  Search manual page names, synopses, and brief descriptions. Matching pages
  are listed in ranked order.

*-K* _keyword_, *--full-text* _keyword_::
  Search the full text of manual pages. Matching pages are listed in ranked
  order.


[[examples]]
== EXAMPLES

.Viewing a program manual page
====
[source,console]
----
$ brlman mged
----
Opens the manual page for the *mged*(1) command, defaulting to section 1.
====

.Disambiguating a name shared by a tool and a GED command
====
[source,console]
----
$ brlman -S n search
----
The name *search* exists both as a standalone tool (section 1) and as a GED
command (section n). The *-S n* selection shows the GED command page instead
of the default tool page. The equivalent positional form is
`brlman search n`.
====

.Browsing documentation graphically
====
[source,console]
----
$ brlman -g
----
Forces the graphical viewer and, because no page was named, opens a browsable
index of all installed programs, libraries, conventions, and GED commands.
====

.Searching all manual page text
====
[source,console]
----
$ brlman -K "boolean operations"
----
Lists pages whose full text contains the search terms, with higher-ranked
matches first.
====


.Dumping a manual as formatted text
====
[source,console]
----
$ brlman --dump --width 72 mged > mged.txt
----
Writes readable text without launching a pager or graphical viewer.
====
