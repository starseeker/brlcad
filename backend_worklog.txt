Obol/libbrlobol Backend Worklog
===============================

Last compressed: 2026-07-07

Purpose
-------

This file preserves a short migration history for backend ownership.  The old
append-only details were intentionally collapsed because they no longer worked
as a handoff document.  Use git history for exact file-level changes,
`backend_capabilities.txt` for current backend state, and `obol_activework.txt`
for active next steps.

Backend Migration Summary
-------------------------

Scene/source ownership:

* GED gained an Obol scene controller and active database draw ownership moved
  to Obol/libbrlobol.
* Database draw, erase, redraw, path-state, bounds, material, source-summary,
  and source-record behavior use neutral/Obol paths.
* Retained BSG database-source records are no longer an active fallback for
  migrated behavior.

Feature/polygon/selection ownership:

* View features, annotations, polygons, line sets, selection synchronization,
  picking, snapping, and measurement gained Obol/libbrlobol adapter coverage.
* Native view contexts do not create BSG storage for missing scene behavior;
  they return empty/no-op results unless an Obol adapter is installed.

Command-scene ownership:

* Diagnostic and command-inserted visuals moved into the Obol command-scene
  model rather than raw OpenGL or retained BSG one-offs.
* Covered families include rtcheck overlap lines, NIRT/qray visuals, GQA,
  BREP/NMG debug shapes, overlay uplot import, `vdraw send`, and preview eye
  paths.

Render/export/readback:

* Obol record/export queries exist for migrated scene objects.
* Old tests that depended on retained display records were removed or marked
  for Obol replacement when they were sole coverage.
* Remaining readback cleanup is tied to application display-host migration.

Display stream and framebuffer:

* qtcad normal painting moved to Obol.
* qged fbserv traffic uses libbrlobol image stream presentation.
* GSH and MGED gained Obol attach/screengrab and ERT smoke coverage.
* fbserv packet ownership remains in libdm pending a later move to a small
  image/framebuffer protocol layer.

libbv and view contexts:

* A clean libbv scaffold was added for non-scene view mechanics.
* librt native view contexts are libbv-backed.
* Public neutral wrappers still need to move out of legacy BSG source files.

CAD and LoD performance work:

* Obol CAD/source-local packet support was integrated where it improves source
  and view-LoD publication.
* Root/group aggregation was tested and not kept because measured gains did
  not justify the complexity.
* Current optimization focus is stronger primitive/source geometry reuse,
  batched publication, and progressive background refinement.

Current Remaining Work
----------------------

1. Delete or migrate remaining production retained-BSG and scene-ref callers.
2. Move neutral RT wrappers out of `view_legacy_bsg.c`.
3. Finish qged, MGED/TclCAD, and GSH Obol host cleanup.
4. Move framebuffer protocol ownership out of libdm after ERT behavior is
   stable.
5. Harden cache-backed progressive drawing and autoview settlement.
6. Replace remaining legacy draw/image baselines with verified Obol baselines.
7. Remove libbsg tests and internals as soon as equivalent Obol coverage
   exists.
