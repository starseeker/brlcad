BRL-CAD Obol Debug Draw Performance Notes
=========================================

Scope
-----

These numbers characterize the current unoptimized debug build using
`build/bin/ged_draw_perf`, the source target in `src/gtools/ged_draw_perf.cpp`.
All listed runs used `--profile --autoview --render`, a 512x512 Obol DM, and a
fresh temporary cache directory with `--clear-cache`.

Interpretation
--------------

Normal wire is not dominated by primitive plotting: plot/vlist conversion is
small compared to source realization, replacement, and render traversal.  The
previous CAD aggregation experiments were not retained because measured
complexity outweighed the benefit in this build.

LoD wire improves rendered point count and render time for Generic_Twin, but
source publication remains the draw-time bottleneck.

Full shaded and hidden-line style paths are tessellation dominated on
implicit-heavy models.  That is a shaded-mode optimization task, not a grid or
faceplate regression.

Evaluated wire is dominated by the librt candidate pipeline.  With
`RT_EVAL_WIREFRAME_PROFILE=1`, `Generic_Twin.g all -m3` reported:

* total evaluated-wire profile time: 10.77 s;
* candidate stages: edge candidates 1.13 s, intersection candidates 3.78 s,
  intersection face indexing 1.92 s, pair evaluation 1.44 s;
* boolweave candidate evaluation: 1.18 s.

The shorter `evaluated-wire boolweave eval summary` reports only the
candidate-eval portion, not total candidate setup/export time.  Thin-shell
havoc evaluated-wire remains a separate long-term algorithm task.

Fixes From This Pass
--------------------

Evaluated-points mode previously aborted on some Generic_Twin CLINE samples
because `rt_cline_norm` called `bu_bomb` on degenerate grazing normals.  CLINE
normal calculation now falls back to a radial normal and otherwise lets the
sampler discard an empty normal.  `Generic_Twin.g all -m5` and
`havoc.g havoc -m5` now complete.

Next Optimization Targets
-------------------------

* Reduce normal-wire source publication/render traversal overhead without
  reintroducing high-complexity CAD aggregation unless fresh benchmarks prove
  it pays.
* Rework full shaded/hidden-line tessellation diagnostics and cost behavior.
* Redesign evaluated-wire candidate generation for large and thin-shell
  models; boolweave itself is not the dominant Generic_Twin cost.
